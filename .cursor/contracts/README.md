# Contratos do domínio Toponímia

Pasta para contratos JSON **deste** projeto (não copiar de outros produtos).

## Planejado (P1)
| Arquivo sugerido | Conteúdo |
|------------------|----------|
| `ruas.json` | Campos usados pelo FE (Home, Admin, Estatísticas, Mapa) |
| `bairros.json` | Capa, slug, título, descrição |
| `onim-tools.json` | Tools do agente (busca, stats, contribuição) |
| `contribuicoes.json` | Insert em `contribuicoes_chatbot` |

Schema SQL oficial: `supabase/migrations/`.
